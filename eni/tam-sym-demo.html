Every symbol below is drawn by a JavaScript function from geometric primitives — there is no image, no font and no external asset. The whole pack is one file, zero dependencies, and renders identically in the viewer, in a training module, in an offline snapshot and in the print/PDF path.

8 · State and data quality are two different layers

The shape colour is the operational state. The dot is the project's data_status — how much the row is trusted. A breaker can be perfectly closed and still be CONFLICT data. Phase 11 already draws the dot; this keeps that convention and adds the state layer above it.

Nothing below is hand-drawn. Each node is one TamSym.draw() call and each conductor one TamSym.flow() call, exactly as a renderer walking v_sld_nodes / v_sld_edges would emit them. The meter prints what it measures, on the line it measures.
